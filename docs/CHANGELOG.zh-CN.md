# 《深空枪匠》0.1.0 更新公告
## 新枪械、新工坊与全新供货渠道

本次更新扩展了枪械收藏与改装内容，并将生产、采购和收纳功能整合进主模组。

### 新增枪械与配件
- 新增 **11款现实枪械**，包括TT-33、SVT-40、SKS、M4A1、MP 40等。
- 加入《DOOM》**BFG 9000**，按狙击枪类定位，性能与价格高于巴雷特。
- 新增 **36件改装配件**，涵盖瞄具、枪托、握把、枪口、扳机组、镀层及专属改装。
- 扩展枪械卖家与顾客改装订单候选。

### 全新生产系统

**CNC枪匠万能机床**
- 替换旧机床，支持64项配方、材料储备、批量加工与跨夜生产。
- 每投入1件材料，可兑换以下对应储量：

| 材料 | 增加储量 |
|---|---:|
| 金属锭：极低／低／普通纯度 | 75／85／100点金属 |
| 金属锭：高／极高／完美纯度 | 125／150／300点金属 |
| 普通电子元件 | **25点电子储量** |
| 3D打印耗材 | **25点打印耗材储量** |
| 核废料 | **500点核废料储量** |

**弹药制造台**
- 支持23种弹药配方，整批一晚完成，消耗8电。
- 每投入1件材料，可兑换以下对应储量：

| 材料 | 增加储量 |
|---|---:|
| 无烟火药和底火 | **100点火药与底火储量** |
| 弹壳堆 | **100点弹壳储量** |
| 弹头堆 | **100点弹头储量** |
| 核废料 | **500点核废料储量** |

两台机器的**各类储量上限均为5000点**，材料需拆成自有单件投入，超额不收；核废料仅作封存储备，不参与现有配方。支持缺电暂停、满仓保留和连续输出。

### 批发与供货
- 整合**枪械批发商**，提供枪械、供弹配件和弹药批量采购。
- 加入**和平余量工业**电话供货服务，支持大小单、次日配送、股东优惠及免费快递分红。
- 两台机器接入博士供货渠道。

### 平衡与体验优化
- 降低多数CNC配方及全部弹药配方的材料消耗，调整供货价格。
- 普通电子元件与3D打印耗材每件可兑换 **25点储量**。
- 整合专用枪架、配件箱和弹药箱，整理贴图比例、枪械朝向及部分配件外观。
- 修复堆叠重复产出、重复扣电、批量输出及供货消费统计等问题。

### 中英文本全面整理
- 补齐全部新增物品的中英文名称与游戏风格简介。
- 清除名称中的“测试”等开发字样，补全部分枪械汉化。
- 两台机器的简介包含使用方法和材料兑换比例。
