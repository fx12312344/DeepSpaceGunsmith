# Source and Asset Provenance

## Maintainer statement

The maintainer confirms that the code and artwork in this mod were generated locally. The project used AI-assisted development and AI-generated inventory artwork, followed by local editing, transparency cleanup, fitting and composition.

This statement describes the creation process. It is not a certification that every output is copyrightable or free of third-party rights.

## Included material

- Mod-specific C# source files, JSON definitions and localization text.
- Inventory images under `assets/` and the business-card background under `Paper/`.
- Project documentation and bilingual release notes.

## Excluded material

- Probably Stolen game assemblies and Unity/Harmony/Steam runtime binaries.
- Decompiled game research, saves, personal backups, logs and account credentials.
- SteamCMD executables, cached authentication, upload configuration and machine-specific build paths.

The mod calls APIs provided by the installed game. That dependency does not grant a redistribution license to the game's binaries or documentation.
